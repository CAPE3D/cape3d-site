# CAPE3D — V7 direction immersive claire

Cette version remplace intégralement la direction visuelle précédente : fond blanc minéral, typographie éditoriale, palette sauge/gris, grande scène WebGL persistante et récit piloté par le scroll.

## Développement

```bash
npm install
npm run dev
```

## Build GitHub Pages

```bash
npm run build
npm run preview
```

Le projet cible le dépôt GitHub Pages `cape3d.github.io/cape3d-site` avec `base: '/cape3d-site'`.

Le formulaire est une préparation d'e-mail `mailto:` : les fichiers sélectionnés doivent être ajoutés manuellement avant l'envoi. Il ne s'agit pas encore d'un téléversement serveur.

Les images de procédés existantes sont conservées comme visuels de contenu, mais toute l'ancienne direction graphique et ses compositions de page sont remplacées.
